# CRM Atlas

Sistema de CRM (Customer Relationship Management) para prospecção e gestão de clientes.

## Estrutura do Projeto

- **CRM_atlas.html** - Versão principal do CRM
- **CRM_atlas_v2.html** - Versão 2 do CRM
- **CRM_atlasv3.html** - Versão 3 do CRM
- **atlas-crm/** - Submódulo com implementação adicional
- **DESIGN.md** - Documentação de design
- **PRODUCT.md** - Documentação de produto

## Como Executar

Abra qualquer um dos arquivos `.html` diretamente no navegador para visualizar o CRM.

## Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)
